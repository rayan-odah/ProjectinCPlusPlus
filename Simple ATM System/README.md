A simple and interactive Automated Teller Machine (ATM) system built with C++. This console-based application simulates real-life ATM functionalities, providing a secure and seamless experience for managing client transactions.



\##  Features



\* \*\*Secure Login System:\*\* Verifies users using their Account Number and PIN Code.

\* \*\*Quick Withdraw:\*\* Allows users to quickly withdraw predefined amounts (20, 50, 100, 200, 400, etc.).

\* \*\*Normal Withdraw:\*\* Custom withdrawal for amounts in multiples of 5.

\* \*\*Deposit:\*\* Users can securely deposit positive amounts into their accounts.

\* \*\*Check Balance:\*\* Instant viewing of the current account balance.

\* \*\*Persistent Data Handling:\*\* Uses File I/O (`Clients.txt`) to save and retrieve client data, ensuring that account balances are updated correctly across sessions.



\## Technologies Used



\* \*\*C++:\*\* Core programming language.

\* \*\*File I/O:\*\* `<fstream>` for reading and updating client records.

\* \*\*Data Structures:\*\* `std::vector` and `structs` for memory management and data organization.

\* \*\*Enums:\*\* Used for clean and readable menu selections.
